# React + Ant Design 项目模板功能特性

## 🎯 项目概述

这是一个生产就绪的 React + Ant Design 项目模板，包含了现代前端项目开发所需的完整功能栈，可以作为企业级应用的基础模板使用。

## ✨ 核心功能

### 🏗️ 技术栈
- **React 19** - 最新版本的 React
- **TypeScript** - 类型安全
- **Vite 7** - 现代化构建工具
- **Ant Design 5** - 企业级 UI 组件库
- **React Router 7** - 客户端路由

### 🔐 权限控制系统
- **路由级权限** - 根据用户权限动态渲染路由
- **菜单级权限** - 动态生成用户可访问的菜单
- **按钮级权限** - 细粒度的操作权限控制
- **权限组件** - `PermissionButton`、`PermissionRoute`
- **权限 Hook** - `usePermission` 提供权限检查功能

### 🌐 国际化 (i18n)
- **多语言支持** - 内置中英文语言包
- **动态切换** - 实时语言切换无需刷新
- **Ant Design 集成** - 自动适配 Ant Design 组件的本地化
- **扩展性** - 易于添加新语言
- **持久化** - 用户语言偏好本地存储

### 📝 表单处理
- **Formik 集成** - 强大的表单状态管理
- **Yup 验证** - 声明式表单验证
- **通用表单组件** - `FormikForm` 支持多种字段类型
- **字段类型** - 文本、密码、数字、选择、日期、复选框等
- **错误处理** - 完整的错误显示和处理机制

### 🔄 HTTP 请求
- **Axios 封装** - 统一的请求处理
- **请求拦截** - 自动添加认证 token
- **响应拦截** - 统一错误处理和消息提示
- **请求缓存** - 内置缓存机制，可配置 TTL
- **错误处理** - 401、403、404、500 等状态码处理
- **取消请求** - 支持请求取消机制

### 📱 移动端适配
- **响应式设计** - 基于 CSS Grid 和 Flexbox
- **设备检测** - `useDevice` hook 检测设备类型
- **断点管理** - 内置移动端、平板、桌面端断点
- **侧边栏适配** - 移动端自动收起侧边栏
- **触摸优化** - 移动端友好的交互体验

### 🎨 主题与样式
- **Ant Design 主题** - 可配置的主题系统
- **CSS 变量** - 支持动态主题切换
- **深色模式** - 预留深色模式接口
- **自定义样式** - 灵活的样式覆盖机制

### 🏠 布局系统
- **主布局** - 完整的后台管理布局
- **侧边栏** - 可折叠的导航菜单
- **顶栏** - 用户信息和全局操作
- **面包屑** - 自动生成的导航路径
- **内容区** - 响应式的主内容区域

### 🔧 工具函数与 Hooks
- **认证 Hook** - `useAuth` 处理用户认证状态

- **工具函数** - 深拷贝、文件大小格式化、随机字符串等

## 📋 使用示例

### 权限控制
```tsx
// 权限按钮
<PermissionButton permissions={['user:create']}>
  创建用户
</PermissionButton>

// 权限路由
<PermissionRoute permissions={['admin']}>
  <AdminPanel />
</PermissionRoute>
```

### 表单处理
```tsx
const fields = [
  { name: 'username', label: '用户名', type: 'text', required: true },
  { name: 'email', label: '邮箱', type: 'email', required: true }
];

<FormikForm
  fields={fields}
  validationSchema={schema}
  onSubmit={handleSubmit}
  initialValues={{ username: '', email: '' }}
/>
```

### API 请求
```tsx
// 带缓存的请求
const response = await httpClient.get('/api/users', {
  cache: { ttl: 5 * 60 * 1000 }
});
```

### 国际化
```tsx
const { t } = useTranslation();
return <Button>{t('common.save')}</Button>;
```
